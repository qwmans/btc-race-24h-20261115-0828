A deterministic, long-only cbBTC/USDC dip-rebound bot using a 30-bar SMA, rebound confirmation, 60% cash sizing, a 0.6% take-profit and a 1.4% stop-loss. Paper trading only; no real orders are placed.

Bounty: [Race a BTC trading bot live for 24 hours](https://make.fun/bounty/btc-race-24h-20261115-0828).

## Run it

```sh
node main.ts
```

Run from the repository root with Node.js 22. No dependency-install step is required. The entry reads the official newline-delimited protocol from stdin and writes replies to stdout.
